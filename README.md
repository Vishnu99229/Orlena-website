# Orlena Website

This is the public-facing website for Orlena, a QR-based restaurant ordering system that helps restaurants increase their average order value using AI.

## Features
- Landing page with hero, problem/solution, and features
- ROI / Food Cost Calculator
- Pricing and Integrations
- Blog and SEO pages

## Setup
```bash
npm install
npm run dev
```

## Tech Stack
- React
- Vite
- Tailwind CSS
- TypeScript
- Framer Motion
